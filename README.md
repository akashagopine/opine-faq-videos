# Opine FAQ videos

Short product walkthroughs embedded in the Opine FAQ knowledge base.

Each file is named for the FAQ answer it belongs to, so
`clips/faq-connect-crm.mp4` is the clip on the "connect your CRM" answer.
Served over GitHub Pages because GitBook renders a direct mp4 URL as an
inline player only when the host serves it cleanly.

Recorded against a seeded demo organisation, not customer data.
